# ジャービス（Android）

スマホで動く、執事型AIアシスタント。

## インストール
1. スマホでこのリポジトリの **Releases**（最新版）を開く
2. `jarvis-v0.1.xx.apk` をタップしてダウンロード
3. 「提供元不明のアプリ」の許可を求められたら、ブラウザに許可してインストール

## できること（v0.1）
- マイクボタンで話しかける → 声で返事
- タイマー・アラーム（スマホの時計アプリに登録）
- 「〇〇を開いて」でアプリ起動
- メモの追加・読み上げ・削除
- 時刻・日付
- 自由な会話（Gemini 無料APIキーを設定画面で登録）
- 会話モード（話し終わると自動で次を聞き取る）
- 「アシスタント」として登録すると、ホームボタン長押しなどで即起動
- 声の調整（調声）: 設定 →「声の調整」で自由に作り込める（下記）
- 呼びかけで起動: 常駐中に「ジャービス」と呼ぶと、「ピッ」と鳴ってすぐ聞き取りを始める（下記）

## 呼びかけで起動
設定 →「呼びかけで起動」で、呼びかけの言葉を自分の声で 3 回録音して登録し、「呼びかけを待つ」をオンにする。

- **端末の中だけで動く**: ネット接続もモデルのダウンロードも不要。声の特徴（MFCC）だけを保存し、録音は残さない
- **すぐ反応する**: 言い終えてから約 0.1 秒で検出し、「ピッ」と振動で合図して聞き取りを始める（`WakeWord.java`）
- **電池**: 声がしていない間は音量を測るだけで、特徴の計算も照合もしない
- **言葉は自由**: 「ジャービス」以外でも、登録した言葉で反応する
- 反応しにくい・反応しすぎるときは「反応のしやすさ」で調整し、「反応をテストする」で近さを確かめられる
- アプリの画面を開いている間は呼びかけ待ちを休む（画面のマイクボタンを使う）
- 画面をすぐ開くには「他のアプリの上に表示」の許可（光の玉と同じ）が要る。許可がないと Android が後ろからの
  起動を止めるので、代わりに「お呼びでしょうか」の通知を出す
- Android 14 以降は、スマホの再起動直後はマイクを使う常駐を始められない。アプリを一度開くと呼びかけ待ちに戻る

合成音での試験（`WakeWordTest`）: 既定の感度で、声の高さ・速さ・音量・雑音を変えた呼びかけ 200 回中 198 回を検出し、
別の言葉 400 個への誤反応は 2 回。実際の声・部屋での精度は端末で確かめて感度を調整する。

## 返事の速さ
話し終わりから声が出るまでを短くするために:

- **返事を流しながら受け取り、文ができた順に話す**: AI の返事を最後まで待たず、最初の「。」まで届いたら読み上げを始める
  （長い文は読点で区切って先に話す）。調声で加工するときも、1 文目を鳴らしている間に 2 文目を加工する
- **考える時間を省く**: Gemini の「思考」を止めて返事を始める（設定の「じっくり考えて答える」で戻せる）。
  思考を止められないモデルは自動で判別して、次からは付けない
- **接続を先に作る**: 話している間に頭脳への暗号化接続を作っておき、返事を頼むときに使い回す
- **話し終わりの判定を短めに**: 無音 0.9 秒で話し終わりとみなすよう音声認識に頼む（対応していない端末では従来どおり）
- 設定画面に「前回の返事: 話し終わりから声が出るまで N 秒」を表示する

## 声の調整（調声）
決まったテンプレートではなく、項目ごとに値を決めて声を作る。スライダーか数値で入力し、離すと試し聞きできる。

| 項目 | 範囲 | 内容 |
|---|---|---|
| 元になる声 | 端末の日本語の声 | 加工の元になる読み上げの声 |
| 話す速さ / 声の高さ | 0.3〜2.5 / 0.3〜2.0 | 読み上げエンジンの設定 |
| 声の太さ | 0.75〜1.35 | 高さを変えずに声の響き（フォルマント）だけ変える。小さいほど太く大人っぽい |
| 低音 / 高音 | ±12dB | 低音（220Hz 以下）・高音（3.5kHz 以上）を強める・弱める |
| 機械っぽさ | 0〜1 | 金属的な共鳴を混ぜる |
| エコー / エコーの間隔 | 0〜0.8 / 40〜600ms | やまびこ |
| 響き | 0〜1 | 部屋の残響 |
| 音量 | 0.3〜2.0 | 1 を超えると増幅（割れないよう自動で抑える） |
| 文と文の間 | 0〜1000ms | 文の終わりに足す間 |

- **初期設定の声「ジャービス（初期設定）」**: 落ち着いた執事の話し方（やや低め・高音を抑えた柔らかい音・少しゆっくり・
  文の間を取る・ほんのり機械的な響き）。初めて起動したときに自動で使い、男性の声が入っていれば元の声にする。
  「保存した声」にいつも出て、消せない。すでに声を変えている人の設定はそのまま
- **保存した声**: 名前を付けて何個でも保存・切り替え・削除できる
- **共有コード**: 今の声を文字列に書き出し、別のスマホで読み込める
- **読み方の辞書**: 「書き方=読み方」を 1 行ずつ。読み上げのときだけ置き換える（例: `JARVIS=ジャービス`）

速さ・高さ・音量（1 以下）・文の間だけなら、読み上げエンジンでそのまま話す。それ以外の項目を使うと、
読み上げた音声を一度ファイルに書き出して加工（`VoiceFx.java`）してから鳴らすので、話し始めが少し遅れる。
加工できなかったとき（音声の形式が想定外など）は、加工なしでそのまま話す。

## しくみ
- `app/src/main/assets/index.html` … 画面と会話ロジック
- `app/src/main/java/.../MainActivity.java` … 声・マイク・タイマー・アプリ起動・通信
- `app/src/main/java/.../Speaker.java` / `VoiceFx.java` … 読み上げと調声（加工は Android に依存しないので PC の JUnit で試せる）
- `app/src/main/java/.../WakeWord.java` / `WakeListener.java` … 呼びかけの検出（検出は Android に依存しない）と、常駐中のマイク
- `.github/workflows/build.yml` … main に push すると GitHub が自動で APK を作って Releases に置く（PR ではビルドと単体テストだけ）

- `agent/` … Termux 上で動くオンデバイス・エージェント（ADB/Shizuku で端末を操作、ローカル LLM）。詳細は [agent/README.md](agent/README.md)

APIキーはコードに含めず、アプリ内の設定画面からスマホにだけ保存する。
